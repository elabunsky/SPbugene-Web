# SPbugene News

Русскоязычная новостная лента: сервер собирает материалы из RSS, Telegram и X, переводит и редактирует их через GLM-5.3, сохраняет фотографии локально и обновляет сводку каждые четыре часа.

## Локальный запуск

Нужен Python 3.9+ и доступ к совместимому с OpenAI Chat Completions API.

1. Скопируйте config.example.json в config.json и укажите свой API-ключ. config.json не добавляется в Git.
2. Создайте папку www и скопируйте в неё index.html.
3. Запустите python3 app.py.
4. Откройте http://localhost:8787/. Для немедленного обновления отправьте POST-запрос на /collect.

Статус доступен по /state.json, готовая лента — по /summary.json. На сервере с публичным доступом используйте HTTPS через обратный прокси. Рабочие конфиги сервера, ключи и сгенерированная лента намеренно не входят в репозиторий.
